# 复古未来主义封面提示词

创作一张 16:9 横版微信公众号教程章节封面，中文模式，单张图。主标题“第九章 常见坑汇总”，副标题“避坑指南、故障排查”。

采用唯一风格“复古未来主义 / retro-futurism”。描绘一座信息分拣设施中的故障排查节点：主输送轨道上有三处可辨认的物理陷阱——堵塞的纸带、接错的管道阀门、熄灭的连接指示灯；一名微小排障员拿着放大镜和维修档案，沿一条黄色检修线逐项处理，最终把消息流引回正确的桥接舱。所有坑是系统中的真实阻塞与纠错，不是危险戏剧。标题作为墙面警示档案牌清晰呈现，副标题在维修标签上。

复古未来主义材质：象牙旧纸、赭红、铁锈橙、炭黑、石油青、芥末黄，旧金属、管道、纸档案、玻璃和铆钉；半色调、纸纤维、褪色油墨、轻微套印偏移。禁止现代故障列表 UI、夸张爆炸、霓虹、HUD、代码雨、随机机器人、密集小字、伪文字、水印与 generic tech 素材。
