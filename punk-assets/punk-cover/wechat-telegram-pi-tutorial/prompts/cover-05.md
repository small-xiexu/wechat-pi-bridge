# 复古未来主义封面提示词

创作一张 16:9 横版微信公众号教程章节封面，中文模式，单张图。主标题“第五章 Telegram 通道搭建”，副标题“Telegram Bot API 接入”。

唯一采用“复古未来主义 / retro-futurism”。把 Telegram Bot API 接入表现为一座太空时代公共电报交换站：左侧一座带 Telegram 标签的输入塔把带有消息孔洞的纸带送入中央机械交换舱，工程师正在插入一枚实体 bot 接口插销；右侧输出轨道通向 Pi 服务核心。只能有一条清楚的信息流与一次连接动作，标题印在交换站顶部的珐琅站牌上，副标题成为一张真实电报标签。

使用赭红、石油青、象牙纸、炭黑、褪色蓝和芥末黄，厚玻璃、涂漆钢、纸带、铆钉、混凝土，复古科幻杂志插画，半色调、纸纤维、旧油墨磨损。Telegram、Bot API、Pi 作为少量准确标签。禁止现代 API 文档截图、聊天窗口、霓虹、悬浮 UI、代码雨、机器人头像、随机电缆、过量小字、伪文字、水印和 PPT 信息图感。
