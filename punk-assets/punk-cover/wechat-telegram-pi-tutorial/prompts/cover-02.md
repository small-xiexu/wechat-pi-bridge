# 复古未来主义封面提示词

创作一张 16:9 横版微信公众号教程章节封面，中文模式，单张图。主标题“第二章 整体架构”，副标题“微信 / TG 双通道经桥接服务接入 Pi 的系统架构”。

使用唯一风格“复古未来主义 / retro-futurism”。把系统架构转译为一座可见、可触摸的 1950s 模拟基础设施：左侧微信入口与右侧 Telegram 入口是两座带真实标签的通信塔，消息纸带沿两条不同颜色的管道进入中央“桥接服务”分拣舱，再沿一条主轨道进入远处标记 Pi 的核心计算大厅，最后输出统一答复。所有组件有物理因果关系，中央轴线、汇聚线和前中后景层次明确；一名微小工程师在中央节点校准阀门。标题印在上方横梁的建筑标牌上，完整可读，不遮挡架构流线。

旧纸赭红、石墨黑、石油青、铁锈橙、褪色蓝，涂漆金属、玻璃、混凝土、纸档案、铆钉；复古科幻杂志插画、半色调、纸纤维、旧油墨磨损、轻微套印漂移。仅少量功能标签：微信、Telegram、桥接服务、Pi。禁止现代网络拓扑图、卡片式信息图、霓虹蓝紫、全息 HUD、代码雨、悬浮 UI、随机机器人、无因果机械堆叠、密集伪文字和水印。
