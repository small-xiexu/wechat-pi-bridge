# 复古未来主义封面提示词

创作一张 16:9 横版微信公众号教程章节封面，中文模式，单张图。主标题“第六章 微信通道搭建”，副标题“微信扫码登录、iLink 通道与语音转写”。

使用唯一风格“复古未来主义 / retro-futurism”。设计一座 1950s 公共通信接入站：小型人物举起实体二维码登录卡，在大型扫码光学闸门前完成认证；通过 iLink 标记的管道，微信消息纸带与一卷带声波纹理的语音胶片进入同一个转写舱，再输出清晰文本纸条。扫码、通道、语音转写必须是一条连续物理流程。标题成为上方接入站建筑的复古标牌，文字清晰，副标题作为少量功能标签。

旧纸、赭红、石油青、铁锈橙、炭黑、褪色蓝；玻璃光学闸门、金属、纸卡、胶片、混凝土与铆钉；半色调、纸纤维、褪色油墨、轻微套印漂移。禁止手机截图、现代二维码海报、霓虹蓝紫、HUD、漂浮 UI、代码雨、卡通人物、随机设备、伪文字、水印与课程封面模板。
